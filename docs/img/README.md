# Imagens do projeto (v2)

| Arquivo | Uso |
|---|---|
| `infografico_animado.gif` | infográfico do pipeline animado — topo do README do projeto |
| `infografico.png` | versão estática em alta resolução (2160×2700) — link no README, carrossel |
| `infografico_animado.mp4` | vídeo de 1080×1350, 30 fps (post do LinkedIn; o vídeo é reproduzido no feed) |
| `infografico_animado.html` | fonte editável, com os botões de exportação para PNG, MP4 e GIF |

Os quatro arquivos já trazem os valores reais do DW (59,1 mil linhas de indicadores, 10,6 mil projetos, 18,1 mil
eventos, 8,12 bi de pessoas, 91,9% com eletricidade). Ao mudar o HTML, exporte de novo pelo próprio navegador
(Chrome no desktop, fonte Inter instalada): PNG em escala 2, MP4 e GIF com um ciclo de 12 s.

O layout das páginas do Power BI está descrito em texto em `powerbi/GUIA_POWERBI.md` (seção 7). Ao gerar prints
do relatório real, salve-os aqui (por exemplo `dashboard/01_visao_global.png`) e adicione-os à seção "Dashboard"
do README.
